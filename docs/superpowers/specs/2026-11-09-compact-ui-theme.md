# AutoVPN v2.0.1 界面改版

## 本地 Issue 草稿

原有六页采用较大的页头、导航底板和多层卡片，重复介绍挤占内容；数字输入随弹窗拉宽，列表无法调整列，浏览器预览错误显示 Electron 拖动区。界面缺少主题选择和真实数据统计，宽表还可能将整个工作区横向挤出边界。

用户在实际预览中进一步要求：订阅并入结果，只保留默认链接；运行操作只在首页状态区出现；侧栏可收缩；国家与加速器贡献使用图表；每日节点产出使用贡献日历；阶段列表内部滚动并显示实际 APK 与域名处理；桌面和服务版网页共用业务。

## 依据与方向

产品用于节点采集、去重、测速、可达性、部署和订阅管理。原始、去重、测速通过和最终可用计数支持判断处理损耗，节点表保留名称、IP、协议与 path。品牌沿用紫色，普通标签使用系统无衬线，地址与路径使用等宽字体。

独立概念生成与概念审查比较了两个方向：A 保留侧栏及现有业务归属，从流水线状态进入结果；B 改用顶部导航和节点主视图，从产物进入运行。两案经状态、草稿和输入方式补正后通过设计可行性检查。采用 A，复用现有导航和编辑草稿；随后依据用户预览反馈将订阅移入结果，最终保留概览、运行、结果、日志、设置五个入口。

旧界面证据曾在 `/tmp/autovpn-ui-before/` 实际查看。独立视觉审查发现移动日志工具栏分散、格式切换难发现和重复空历史；日志操作已同排，格式切换已按最新业务删除，空历史只保留运行选项。代理审查只支持所见画面，实际交互另由浏览器测试核验。

```text
概览  状态与运行图标 → 四阶段计数 → 国家 / 加速器环形图 → 每日产出日历
运行  历史重试与选项 → 可滚动阶段及真实子步骤 / 当前阶段
结果  默认订阅与二维码入口 → 节点表 → 按需部署明细
设置  图标入口 → 主题 → 账号工具与可调列表
```

## 实现决定

应用外壳不重复显示页标题、介绍或独立操作栏。运行与停止使用有可访问名称的 SVG 按钮，只在首页状态区保留；运行页的选项在切页后保存。桌面侧栏可收起为图标栏，选择持久化；平板和手机保留可达导航。

复制、刷新、下载、关闭、列设置及二维码采用图标。字段、实际错误和业务状态保持可读；重试解释和重复概况删除。设置弹窗按内容定宽，URL 使用整行，数字字段使用适当宽度；输入、按钮与提交区沿相同边缘对齐。

节点与账号表共用列调宽、拖动顺序、键盘替代、触屏列设置和重置，布局在本地保存。宽表只在自己的容器滚动，页面不横向漂移；较长账号列表和阶段列表内部滚动。滚动条为 4px，活动时显示、闲置隐藏；键盘及强制配色保留可见指示。移动端保留完整字段。

主题支持跟随系统、浅色与深色，覆盖五页、图表和弹窗；切换不提交业务配置。桌面控件保持紧凑，主要操作与触屏命中区域至少 44px。贡献日历的单元格属于数据标记，另验焦点、提示与横向到达。

图表实际复用 beUI DonutChart、HeatCalendar 及其 Tooltip，使用 React 局部挂载、Motion 和 Tailwind 工具样式，构建成随应用分发的本地资源。来源、MIT 许可、固定提交与 API 见同目录 `2026-11-10-beui-component-sources.md`；不依赖运行时 CDN。常规控件沿用现有原生控件与业务组件。

国家分布来自最终节点预览；加速器贡献采用各数据源的独立去重节点数。每日产出从全部保留运行记录汇总最终可用节点，重试列表仍只保留最近 20 项；同一节点在不同运行中会分别计数。日历覆盖当前周及之前 52 周，不生成示例生产数据。

APK 下载、APK 解析和域名探测由真实提取事件驱动，缓存复用单独标识为缓存；不存在事件时不虚构完成状态。运行过程和历史事件可经桌面桥接或网页服务恢复。

账号上传、状态和刷新沿用服务端现有 SQLite 账号池；H5 与桌面使用相同存储实现。预览使用真实服务，保留文件上传后持久化与重新连接验证。

新版透明 Logo 来自内置 imagegen，原件为 `electron/renderer/assets/vpn-auto-logo-v3.png`。PNG、ICO、ICNS 均由它生成并保留透明背景，提示词见同目录 `2026-11-10-logo-v3-generation.md`。应用、npm、锁文件、侧栏与安装示例同步为 2.0.1。
