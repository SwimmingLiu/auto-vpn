# AutoVPN Logo v3

使用内置 imagegen 生成，透明背景开启。原件位于 `electron/renderer/assets/vpn-auto-logo-v3.png`，实际为 1254×1254 PNG；包装图标从该原件缩放生成，不添加底色。PNG、ICO 中嵌入 PNG 的透明角点由测试检查，ICNS 在打包后与项目资源比对。

最终提示词如下。

```text
Use case: logo-brand. Asset type: a single production application logo for AutoVPN desktop and web UI, also used as a macOS app icon. Primary request: redesign a compact, distinctive purple shield mark combining one clean continuous automatic-routing loop with a simple letter A in negative space. Keep the silhouette bold and exceptionally legible at 20–32 pixels. Style: precise flat vector-like geometry with gently rounded joins, restrained violet gradient #7775EE to #5151CE, optional tiny white inner route cutout; no detailed network graph, no thin strokes, no 3D bevel, no glass, no ornamental extra circles. Composition: one centered isolated logo, a unified shield silhouette with subtly rounded top corners, filling approximately 80 percent of a square canvas. Transparent outside the mark, true alpha transparency, no white, black or colored background, no separate rounded-square app tile, no shadow cast onto a background. No text, no wordmark, no watermark, no mockup, no multiple options or grid. This is a practical developer utility for managing VPN subscription pipelines, not a promotional illustration. Deliver one polished original icon with actual transparent background.
```
